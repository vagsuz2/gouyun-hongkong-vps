## **为什么是「香港」而不是别的地方**

先说个最基本的判断。

香港机房最大的优势，不是价格，是**距离**。从广州到香港的物理延迟，正常线路能压到15-30ms，这点日本、韩国勉强追得上，美国机房120ms起步基本不用想。对于做中文站点、跑跳板、科学用途、跨境访问这种**晚高峰也要稳**的场景，香港几乎是默认答案。

但问题就出在「低价」两个字上。

香港机房带宽成本比欧美贵好几倍，所以市面上很多号称「香港低价VPS」的产品，线路其实是国际绕路：电信回程绕新加坡、联通绕日本NTT，移动走普通直连。白天测速漂亮，晚上8点一过丢包率飙到两位数，延迟从30ms蹦到150ms+。这就是为什么很多老站长的口头禅是——「线路名字好听的不一定真便宜，但真便宜的一定要看线路」。

所以挑香港低价VPS，你要盯着三件事看：**线路类型、带宽上限、流量配额**。价格反而排在第四位。

狗云（DogYun）2019年正式起这个牌子，但创始人团队2012年就在搞虚拟主机、2014年进云服务器，算下来也是十几年老兵了。全线产品用KVM虚拟化，自研了一套叫「Dudu」的中文控制面板，主打**弹性计费**——按小时扣费、随时升降配、随时销毁退余额，这点在国内VPS圈子里不算多见。

香港机房他们自营，路线挺杂：除了精品套餐里的CN2+CU+CMI组合，还接了HKIX、EIE、TPIX、NTT、HE、Telstra、Retn、Cogent、GSL、Voxility一堆国际线路。简单说就是——你要便宜的、要稳的、要大带宽的、要大硬盘的，他们都想办法塞了对应的产品线。

狗云目前香港的产品分两大类：

- **弹性云服务器**：按小时计费，配置随开随改，适合短时项目、临时编译、测试环境。香港起步约￥29.52/月。
